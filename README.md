## 仓库状态

本仓库暂未启用。Pudding 的 Web UI 与 Android UI 目前在[主仓 monorepo](https://github.com/Pudding-Player/Pudding) 中维护：

- [`packages/ui/`](https://github.com/Pudding-Player/Pudding/tree/main/packages/ui) —— 共用 React 组件库（npm workspace `@pudding/ui`）
- [`packages/ui-android/`](https://github.com/Pudding-Player/Pudding/tree/main/packages/ui-android) —— Android 模块

UI 源码不在此仓复制或镜像；如未来启用本仓，会在此说明迁移方式。
